Implementation

Write — about 120 words

This section opens where box 2 closes. You have said what the model is and why; this is how it is built.

Two things to cover. First, the variance function: abs(mu) + delta puts a gradient kink exactly where the latent means live, and Stan warns against non-differentiable functions in the likelihood. The squared form is smooth, needs no tuning constant because the smoothing scale is the estimated parameter, and it makes δ twice the geometric mean of the two Poisson rates.

Second, what that bought. φ² − μ² = δ², so the Bessel argument stops varying with the observation — it depends on the data only through the order. 415 special-function evaluations per gradient became 18.

Worth one clause: the latent mean is written centred because that is the model; the fitted version is the non-centred equivalent.

// Skellam in mean-variance form. phi is the variance, and the
// Bessel term is supplied precomputed - see below.
real skellam_lpmf(int y, real mu, real phi, real log_bessel) {
  return -phi + (log(phi + mu) - log(phi - mu)) * y / 2 + log_bessel;
}

// the normal enters as a latent mean, one per observation.
// this is what loosens sigma^2 = lambda1 + lambda2.
mu[n]  ~ normal(theta[n], sigma);
phi[n] = sqrt(square(mu[n]) + square(delta));
// phi^2 - mu^2 = delta^2, so the Bessel argument is now constant across
// observations. it varies only through the order abs(y), which is data.
transformed data {
  array[N] int abs_Y;
  for (n in 1:N) abs_Y[n] = abs(Y[n]);
  int max_Y = max(abs_Y);
}
model {
  vector[max_Y + 1] log_I;                 // once per gradient, not per observation
  for (i in 0:max_Y) log_I[i + 1] = log_modified_bessel_first_kind(i, delta);
}

You have already predicted both failures, so this is confirmation rather than discovery. Point at the prediction each model made and show what it cost.

· Gaussian. You called it an approximation ANOVA is robust to. The figure is where the approximation breaks — at the mode, which is where the data are densest.

· Skellam. You named σ² = λ₁ + λ₂ as the restriction. The figure is what that restriction costs: mass it cannot concentrate. This is the more interesting panel — the Gaussian is what everyone uses, but the Skellam is what a careful person would reach for, and it is still not enough.

Two method notes, one sentence each: the Gaussian’s integer probabilities come from a continuity correction so all three panels share identical geometry; and the replicates are full generative draws, with the latent mean redrawn rather than held at its fitted value.

generated quantities {
  array[N] real mu_rep;
  array[N] int  y_rep;
  for (n in 1:N) {
    // redraw the latent mean rather than holding it at its fitted value
    mu_rep[n] = normal_rng(theta[n], sigma);
    y_rep[n]  = skellam_rng(mu_rep[n], sqrt(square(mu_rep[n]) + square(delta)));
  }
}

Limits

Write — about 150 words. Second-highest-value paragraph on the site.

The numbers are settled: 69 observations sit at a difference of zero, 16.6% of 415. 58 of those — 84% — are sessions with zero entries in both windows. Of those 58, 38 are at the saline dose.

So the excess at zero is structural, not distributional. It is sessions with no occasion setter present and consequently no behaviour to measure. A Skellam has no mechanism for “the animal did not engage” — it only knows about rates. A zero-inflated Skellam is the named extension, and countdiff already specifies zero-inflated, hurdle and zero-deflated variants of every family.
