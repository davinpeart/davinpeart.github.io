Model documentation

A model is not finished when it converges. Specification, priors, diagnostics, per-subject fit and the test belong in one artifact, and I build that artifact every time.

Describing a model

It can be difficult to adequately describe generative models in methods sections with many complex analyses and strict word limits. An effective method of clarifying the structure of these models is visualization (Kruschke, 2015). Each figure visually and compactly communicates the likelihood function selected and its parameters, the regression functions placed on each of these parameters, the random effects parameterization selected, and the priors placed on all parameters. All seven below are drawn at the same scale, so differences in height track how many hierarchical levels each model carries.

Auditing a model

In addition to describing the generative structures of the specified models, an audit of the reliability of the model predictions should be provided (Kruschke, 2021). We can show that the selected priors cover most of the range of plausible parameter values and that the data generating process was adequately described using predictive checks. We can also show that our MCMC chains converged with R̂ and effective sample size histograms. Additionally, sometimes when the population predictions look reasonable, the model might fail catastrophically on some individual subjects — we can show subject-level posteriors to rule this error out. Finally, we can illustrate hypothesis testing of our model parameters in Savage-Dickey Bayes factor plots.

Kruschke, J. K. (2015). Doing Bayesian Data Analysis: A Tutorial with R, JAGS, and Stan (2nd ed.). Academic Press.

Kruschke, J. K. (2021). Bayesian analysis reporting guidelines. Nature Human Behaviour, 5(10), 1282–1291.

Limitations

Although thorough, these plots still do not convey some important information for establishing model trustworthiness. First, the model specified with two non-linear negative binomial models consistently outputs approximately 0.1% divergent transitions owing to weak random effect identifiability. The non-linear function and/or random effects structure should be simplified to remove these divergences. Additionally, these models are shown to be internally reliable, but these figures do not demonstrate that each model’s predictions are accurate for new unfitted observations. Similarly, although reliable, these models are not necessarily the best models, as no model comparisons are demonstrated in these figures.
